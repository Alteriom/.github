# Getting help

## Documentation first

Most answers are in the project's documentation:

- **painlessMesh**: [alteriom.github.io/painlessMesh](https://alteriom.github.io/painlessMesh/)
- **esp32-rig**: [alteriom.github.io/esp32-rig](https://alteriom.github.io/esp32-rig/)
- **LoRa E220 library**: [alteriom.github.io/alteriom-ebyte-lora-e220-library](https://alteriom.github.io/alteriom-ebyte-lora-e220-library/)
- **Everything else**: the repository's README

## Questions

- **painlessMesh**: ask in [Discussions](https://github.com/Alteriom/painlessMesh/discussions).
- **Other projects**: open an issue on the repository and describe what you're trying to do.

## Bugs and feature requests

Open an issue on the relevant repository using the bug report or feature request form.

## Security issues

Don't open a public issue. See the [security policy](SECURITY.md).
