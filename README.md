# Alteriom `.github`

The public organization repository for [Alteriom](https://github.com/Alteriom). It holds two things:

1. **The organization profile**: [`profile/README.md`](profile/README.md) is what visitors see on
   [github.com/Alteriom](https://github.com/Alteriom).
2. **Default community health files**: GitHub applies these to every public Alteriom repository
   that doesn't have its own copy.

## What's here

| File | Applies to | Purpose |
|---|---|---|
| [`profile/README.md`](profile/README.md) | Organization page | Public overview of our open-source projects |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Repos without their own | How to report issues and submit pull requests |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Repos without their own | Contributor Covenant 2.1 |
| [`SECURITY.md`](SECURITY.md) | Repos without their own | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Repos without their own | Where to ask for help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Repos without their own templates | Bug report and feature request forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Repos without their own template | Pull request checklist |
| [`docs/README.md`](docs/README.md) | Maintainers | How to keep the profile and defaults accurate |

A repository's own file always takes precedence over the default here. See GitHub's documentation
on [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## Changing this repository

This repository is public, so everything in it is visible to everyone. Keep internal repository
names, hostnames and infrastructure details out of it. The maintainer guide in
[`docs/README.md`](docs/README.md) covers when and how to update the profile.
