# Changelog

All notable changes to this repository are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 2026-09-28

### Changed

- Rewrote the organization profile to cover all public projects: mesh networking and device
  libraries, telemetry SDKs, the hardware-in-the-loop testing suite and build tooling.
- Rewrote `CONTRIBUTING.md` and `SECURITY.md` as organization-wide defaults. Security reports now
  go through GitHub private vulnerability reporting, with `admin@alteriom.ca` as fallback.
- Replaced the abridged code of conduct with the full Contributor Covenant 2.1.
- Replaced the Markdown issue templates with issue forms, and simplified the pull request template.
- Rewrote the repository README and the maintainer guide in `docs/README.md`.

### Added

- `SUPPORT.md`
- Issue template `config.yml` with links to the security policy and painlessMesh Discussions.

### Fixed

- Removed the placeholder `security@alteriom.example` contact address.
- The repository README no longer describes a different project.

## 2025-10-23

### Added

- Initial profile README, contributing guide, security policy, code of conduct and license.
